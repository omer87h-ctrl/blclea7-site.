AI POMOĆNIK / OPENAI API

Tvoj račun.
Tvoj izbor modela.

Za pomoć pri izradi projekta poveži svoj OpenAI račun u Windows Studiju. Odaberi podržani model, opiši šta želiš i pregledaj prijedlog prije primjene. Studio, Runtime i SDK možeš koristiti i bez AI-ja.

AI koristi tvoj OpenAI API ključ i naplaćuje se direktno kod OpenAI-ja. API potrošnja nije uključena u BLclea7 niti u ChatGPT pretplatu.
KAKO SE POVEZUJE

Kontrola ostaje
kod tebe.

  1. Otvori svoj ovlašteni OpenAI API račun i podesi API naplatu kod pružaoca.
  2. U Windows Studiju otvori AI pomoćnik i odaberi OpenAI API.
  3. Unesi vlastiti ključ, potvrdi pravo upotrebe i provjeri vezu.
  4. Odaberi tekstualni model koji tvoj račun podržava za Chat Completions. Katalog sadrži i druge vrste modela.
  5. Napiši zahtjev i posebno potvrdi slanje opisa i modela projekta.
  6. Pregledaj validirani prijedlog prije primjene. Zatim testiraj aplikaciju i izvoz.
KLJUČ / SAMO OVA SESIJA

Bez ključa u
tvojoj aplikaciji.

  • Ključ se ne upisuje u projekt, APK, .clea7 paket, localStorage ili datoteku postavki.
  • Windows Studio čuva ključ samo tokom sesije i koristi ga za vezu sa službenim OpenAI API-jem.
  • Dugme za zaboravljanje uklanja aktivnu referencu ključa; ne poništava potrošnju, ranije poslane zahtjeve ili podatke kod pružaoca.
  • API ključ unesi samo u AI pomoćnik Windows Studija. Web Studio i HTML pregled ne traže ključ. Nemoj ga dijeliti u razgovorima ili na GitHubu.
PRIVATNOST / ŠTA SE ŠALJE

Cloud zahtjev ima jasnu granicu.

Nakon tvoje potvrde šalju se opis i model trenutnog projekta, uključujući početne vrijednosti. Ova operacija ne šalje runtime bazu, druge projekte, datoteke računara ili historiju izvršnog traga. Nemoj u opis ili početne vrijednosti unositi tajne ili podatke za koje nemaš pravo slanja.

Svaka generacija traži novu potvrdu. Nema automatskog ponavljanja naplativog zahtjeva ili prebacivanja na drugi servis. Odgovor ima ograničenje broja tokena; to nije novčani budžet. Cijenu i limite provjeri u svom API računu.

Zahtjev postavlja store=false, što nije obećanje da pružalac ne zadržava nikakve podatke. Primjenjuju se OpenAI pravila obrade i zadržavanja.

Pregledaj prijedlog. Isprobaj rezultat.

Prijedlog se tretira kao nepouzdan ulaz, parsira i validira, a identitet projekta ostaje sačuvan. Neispravni ili prekinuti odgovori se odbijaju. Model ne izvršava shell komande, ne instalira dodatke i ne dobija slobodan pristup datotekama.

Validan format ne dokazuje funkcionalnost, originalnost, prava na sadržaj niti uspješan build. Korisnik pregledava prijedlog i testira aplikaciju prije distribucije.

Tehničke provjere AI veze

Testovi ugovora provjeravaju HTTPS odredište, zaglavlje autentifikacije, saglasnost, blokirana preusmjeravanja, greške, čuvanje identiteta, odsustvo ključa u izvozu i zaboravljanje. UI test koristi jasno označene testne odgovore; to nije plaćena AI generacija.

Automatske provjere koriste testne odgovore. Stvarna generacija zavisi od tvog API računa, dostupnog modela i podešene naplate; naplativa generacija nije potvrđena ovim testovima.
