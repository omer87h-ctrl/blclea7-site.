Pomoć pri izradi.
Ti biraš kada.

Opiši šta želiš napraviti, pregledaj prijedlog i odluči šta ćeš primijeniti. Studio možeš koristiti i bez AI-ja.

Opcionalni pomoćnik povezuje se s tvojim OpenAI API računom. OpenAI naplaćuje potrošnju direktno tebi; ona nije uključena u besplatni Studio ni u ChatGPT pretplatu.

Preuzmi Windows Studio ↓

Kako ga povezati

  1. Pripremi ovlašteni OpenAI API račun i podesi njegovu naplatu.
  2. U Windows Studiju otvori AI pomoćnik, odaberi OpenAI API i unesi svoj ključ.
  3. Provjeri vezu i odaberi podržani tekstualni model s vlastitog računa.
  4. Opiši ideju, pregledaj šta se šalje i potvrdi zahtjev.
  5. Pregledaj prijedlog prije primjene i isprobaj aplikaciju u pregledu.

Šta se šalje OpenAI-ju?

Nakon tvoje potvrde šalju se opis i struktura trenutnog projekta, uključujući početne vrijednosti. Ne šalju se baza pokrenute aplikacije, drugi projekti ni datoteke računara. U zahtjev ne unosi lozinke, ključeve ili podatke za koje nemaš pravo slanja.

Svaki novi prijedlog traži potvrdu. Cijene, limite i pravila zadržavanja podataka određuje OpenAI.

Kako se čuva API ključ?

Windows Studio čuva ga tokom aktivne sesije. Ključ ne ulazi u tvoj projekt ili izvezenu aplikaciju. Možeš ga ukloniti dugmetom Zaboravi API ključ ove sesije. To ne briše raniju potrošnju ili podatke koje je servis već primio.

Web Studio i HTML pregled ne traže API ključ.

Prijedlog ostaje tvoj izbor

Prije primjene pregledaj sadržaj, a zatim provjeri ponašanje aplikacije. Za korištenje generisanog sadržaja primjenjuju se uslovi pružaoca servisa i prava na materijale koje koristiš.
