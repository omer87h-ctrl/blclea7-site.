Zasebni APK za instaliranje CLEA7 paketa; nije editor Studija.

Javni native paketi još nisu postavljeni. Web Studio, HTML pregled i SDK iznad dostupni su odmah.

Windows x64 ZIP treba raspakovati u cijelosti; priloženi Runtime i prikazivač ostaju u mapi. Android paket je zasebni Runtime, ne Studio. Razvojni Windows izvršni fajlovi nemaju CLEA7 Authenticode potpis, a APK koristi razvojni potpis.

Šta je provjereno?
