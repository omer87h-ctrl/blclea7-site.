Tvoj rad.
Pod tvojom kontrolom.

Za osnovni rad nisu potrebni račun ni pretplata. Projekte uređuješ i čuvaš lokalno.

Gdje se čuva tvoj projekt?

Web Studio čuva projekte u pregledniku, a Windows i Android programi na tvom uređaju. Ne šaljemo ih na naš server. Preuzimaj kopije: brisanje podataka preglednika može ukloniti sačuvani rad.

Samostalni HTML pregled čuva rad do zatvaranja datoteke. Prije zatvaranja preuzmi projekt.

AI koristiš kada ti odlučiš

OpenAI pomoćnik u Windows Studiju traži tvoj API ključ i potvrdu prije slanja opisa i podataka projekta. Web Studio ne traži API ključ. Kako radi AI pomoćnik →

Šta dijeliš s aplikacijom?

Primalac .clea7 paketa može pregledati njegov aplikacijski kod. API ključeve, lozinke i druge tajne drži izvan projekta.

Instaliranje aplikacija

Runtime prikazuje podatke paketa prije instalacije i provjerava može li ga pokrenuti. Biraj aplikacije iz izvora kojem vjeruješ. Više o paketima →
