Web Studio i Runtime

Projekt, instalirana .clea7 aplikacija i njeni podaci ostaju u skladištu ovog preglednika. Ne šalju se na naš server. Privatni način, brisanje podataka i pravila preglednika mogu ukloniti skladište; preuzimaj kopije. Samostalni HTML pregled koristi memoriju sesije.

Ova web verzija ne prikuplja OpenAI API ključeve niti pokreće AI zahtjeve. Opcionalni korisnikov API račun podržan je u Windows hostu uz izričitu saglasnost prije slanja. Detalji AI obrade →

Objavljeni razvojni pregled i SDK smiješ besplatno koristiti za kreiranje vlastitih aplikacija. Svoje aplikacije možeš distribuirati i komercijalno, s neizmijenjenim ugrađenim jezgrom i potrebnim obavijestima. Originalna platforma i oznake ostaju Brzo i Lokalno. Pročitaj pune uslove.

BIL izvor u aplikaciji

Application/5 paketi sadrže BIL izvor i provjereni IR. Autor i korisnik mogu ih pregledati. API ključeve, lozinke i privatne tajne ne stavljaj u kod ili paket. BIL sigurnosne granice.

Sigurnosni model

Runtime provjerava aplikacijski ugovor, integritet, dozvoljene operacije i pripadajuće podatke. Potpis paketa potvrđuje kontrolu ključa, ne pravni identitet ili odsustvo štetnog sadržaja. Instaliraj samo aplikacije čije porijeklo poznaješ.

SHADOW ispituje alternativu na kopiji podataka, a REPLAY ponavlja podržane zabilježene događaje. Podaci se razdvajaju unutar Runtimea; svaka aplikacija nema vlastiti OS proces. Tačne granice ugovora.
