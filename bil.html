Primjer: iznos ponude

Unesi količinu i cijenu, pa dugmetom Izračunaj prikaži ukupan iznos. Primjer možeš urediti u Studiju ili otvoriti vlastitim alatima kroz SDK.

Pogledaj BIL kod primjera
let quantity = 1
let price = 20
let total = 20
screen quote "Moja ponuda" {
    input quantity label "Količina"
    input price label "Cijena"
    button "Izračunaj" runs calculate
    show total
}
on calculate {
    total = quantity * price
}

BIL 0.18: vrijednost koja prati svoje izvore

Sa derive opiši proračun koji treba pratiti promjene ulaza. Izvedenu vrijednost ne mijenjaš ručno: Core je preračuna iz provjerenih zavisnosti. Uvezi stvarni BIL primjer ili instaliraj paket u browser Runtime 0.18-test.

let quantity = 2
let price = 20
derive total = quantity * price

screen quote "Moja ponuda" {
    input quantity label "Količina"
    input price label "Cijena"
    show total
}

Nadogradnja donosi i ograničenu while petlju te tipizirani JSON zapis i čitanje. Na primjer, while count < 3 limit 5 { count = count + 1 } ima izričitu granicu izvršavanja. json.decode provjerava podatak prema zadanom obliku; ne izvršava sadržaj kao kod.

Studio, SDK i Runtime koriste isti kompajler i semantiku Corea. Radni cache može ponovo upotrijebiti čiste rezultate s istim relevantnim ulazima; isključivanje cachea zadržava isti rezultat programa.

Kako uređuješ program?

Dodaj ekran, dugme, unos ili tabelu. Povlačenjem i strelicama mijenjaj raspored unutar reda ili kartice. Izaberi mobilni ili širi pregled i probaj aplikaciju prije izvoza. U vođenom editoru sastavi događaje, uslove i operacije s podacima. Funkcije i složenija pravila možeš uređivati u BIL kodu.

Izgled koji uređuješ vizuelno

U aplikaciji s ekranima otvori BIL jezik i pronađi komponentu u vizuelnom dizajnu. Proširi Izgled i animacija: promijeni boju, razmak, veličinu ili animaciju i pogledaj rezultat. Izmjena ostaje dio istog BIL izvora, uz poništavanje i vraćanje izmjena.

Za nove stilove, oblike i geste koristi Runtime 0.14 ili noviji.

Radi i bez AI-ja

BIL programi ne zahtijevaju AI račun ili model. Za pomoć pri izradi projekta Windows Studio ima odvojeni OpenAI pomoćnik. Napredne mogućnosti povezivanja BIL-a s modelima opisane su u dokumentaciji za developere.

Sačuvaj i pokreni

Preuzmi .clea7 paket i instaliraj ga u kompatibilni Runtime. Za nove Core mogućnosti koristi kompatibilni Runtime: aktuelni web/SDK je 0.41.1-test, Windows 0.42.0-test, a Android 0.40-test. Podaci se čuvaju lokalno u okruženju koje koristiš. Kod u paketu je čitljiv, zato u njega ne upisuj lozinke ili API ključeve.
