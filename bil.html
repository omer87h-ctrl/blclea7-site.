Primjer: izračun ponude

Dvije stavke, tipizirana funkcija i stvaran rezultat 42. Ovaj program radi bez AI servisa. U SDK-u je dostupan kao sdk/examples/bil/core.bil.

import collections
record Item { quantity: Number, price: Number }
fn amount(item: Item) -> Number {
    return item.quantity * item.price
}
const items = [new Item { quantity: 2, price: 15 }, new Item { quantity: 3, price: 4 }]
let total = 0
for item in items {
    total = total + amount(item)
}
let note: Text? = null
let status = "Ukupno je izračunato"
if note != null {
    status = note
}
show total
show status

Vizuelno i u kodu

Vizuelni BIL uređuje početne primitivne vrijednosti i show/visualize prikaze istog izvora. Funkcije i ostali kod ostaju sačuvani. Postojeći JSON i vizuelni projektni editori ostaju dostupni. Opće BIL forme, rasporedi, tabele i native bindingi nisu dio ovog jezičkog ugovora.

AI je izbor

Deterministički izbor prikaza radi bez modela. BIL ima ograničen ugovor za opcionalni AI prijedlog i provjeren fallback; javno izdanje ga ne povezuje automatski s modelom. Postojeći OpenAI pomoćnik Windows Studija ima zaseban tok i saglasnost korisnika.

Podaci i sigurnost

Runtime ponovo provjerava BIL izvor i IR prije izvršavanja. Podaci aplikacije spremaju se lokalno kroz provjerene transakcije. .clea7 application/5 paket uključuje izvor radi te provjere: u kod ne upisuj API ključeve ili druge tajne.

Izvršavanje ima granice instrukcija, vremena i podataka. To nije garancija neprobojnosti ili OS procesa za svaku aplikaciju. Reduced-motion isključuje animaciju. Automatske provjere pokrivaju Chrome, Windows x64 i Android API30 emulator; fizički uređaji i produkcijsko potpisivanje ostaju odvojeni koraci.
