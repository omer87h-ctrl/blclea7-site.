BIL / JEZIK ZA TVOJU APLIKACIJU

Pravila koja napišeš.
Rezultat koji vidiš.

BIL povezuje ekrane, podatke i radnje tvoje aplikacije. Počni bez pisanja koda: odredi polja, prilagodi raspored i odmah isprobaj unos, pretragu i uređivanje. Vlastita pravila možeš dopisati u istom projektu.

Otvori Studio →Preuzmi SDK i Runtime ↓

Izračunaj

Radi s brojevima, tekstom, listama i zapisima. Napiši pravilo za iznos ponude, status zadatka ili promjenu vrijednosti.

Prikaži

Prikaži tekst, broj ili status. Za prikaz napretka odredi raspon vrijednosti. Promjenu broja možeš povezati s kratkom animacijom.

Razumij rezultat

Poslije radnje pregledaj šta je promijenjeno i gdje je nastala greška. Podržanu alternativu isprobaj na kopiji podataka.

Isprobaj prvi program

  1. Otvori Studio i odaberi BIL jezik → Novi BIL projekt.
  2. Promijeni početnu vrijednost u kodu ili vizuelnom polju.
  3. Izaberi Provjeri BIL, zatim Kompajliraj i primijeni i Pokreni BIL.
  4. Isprobaj dugmad aplikacije i pogledaj rezultat.
Preuzmi izvršivi primjer ↓Preuzmi BIL izvor ↓Otvori Runtime →

Primjer: iznos ponude

Dvije stavke daju ukupan iznos 42. U SDK-u možeš otvoriti ovaj primjer, promijeniti količine i cijene pa izračunati novi rezultat.

Pogledaj BIL kod primjera
let quantity = 1
let price = 20
let total = 20
screen quote "Moja ponuda" {
    input quantity label "Količina"
    input price label "Cijena"
    button "Izračunaj" runs calculate
    show total
}
on calculate {
    total = quantity * price
}

Kako uređuješ program?

Dodaj ekran, dugme, unos ili tabelu. Povlačenjem i strelicama mijenjaj raspored unutar reda ili kartice. Izaberi mobilni ili širi pregled i probaj aplikaciju prije izvoza. Funkcije i složenija pravila uređuješ u BIL kodu.

Radi i bez AI-ja

BIL programi ne zahtijevaju AI račun ili model. Za pomoć pri izradi projekta Windows Studio ima odvojeni OpenAI pomoćnik. Napredne mogućnosti povezivanja BIL-a s modelima opisane su u dokumentaciji za developere.

Sačuvaj i pokreni

Preuzmi .clea7 paket i instaliraj ga u Runtime 0.7 ili noviji. Podaci se čuvaju lokalno u okruženju koje koristiš. Kod u paketu je čitljiv, zato u njega ne upisuj lozinke ili API ključeve.
