Prva aplikacija

Otvori Studio → Otvori Runtime →

  1. U Studiju dodaj komponente, stanje i tok događaja. Pokreni pregled i provjeri stvarno ponašanje dugmeta.
  2. Odaberi Preuzmi paket za zasebni Runtime i sačuvaj .clea7 datoteku.
  3. U zasebnom Runtimeu odaberi Instaliraj .clea7. Pregledaj podatke paketa i potvrdi instaliranje.
  4. Pokreni aplikaciju iz biblioteke, izmijeni podatak i ponovo pokreni Runtime da provjeriš čuvanje.
  5. U dijagnostici pregledaj stvarni događaj. Za podržani tok provjeri SHADOW ili REPLAY.
Projekt sačuvaj lokalno i preuzmi njegovu kopiju prije promjene računara ili brisanja skladišta preglednika.

Šta trebam instalirati?

  • HTML pregled: preuzmi datoteku i otvori je u Chromeu. Prije zatvaranja preuzmi projekt.
  • Windows Studio: raspakuj cijelu mapu i pokreni BL_CLEA7.exe. Potreban je Windows x64. RuntimeConsumer sadrži priloženi WebView2; raspakuj i zadrži cijeli paket, uključujući _internal.
  • Android izgradnja: instaliraj JDK 17+, Android SDK 35 i Gradle 8.10.2. Ovi alati nisu uključeni u ZIP Studija. U Studiju možeš izvesti izvor ili pokrenuti lokalni APK build.
  • Zasebni Runtime: izaberi Windows ili Android paket i instaliraj kompatibilnu .clea7 aplikaciju. Za njeno korištenje Studio nije potreban.

Šta sadrži .clea7?

clea7.package/1 je verzionisana JSON omotnica s manifestom, base64 kodiranim sadržajem aplikacije i SHA-256 provjerom sadržaja. Modeli clea7.application/2 i clea7.application/3 imaju verzionisan ugovor. Application/3 dodaje state machines, animacijske trake i biblioteku komponenti; zahtijeva Runtime 0.4.

  • Identitet, ime, verzija, podržani ciljevi i Runtime kompatibilnost.
  • Komponente, podaci i dozvoljeni tokovi događaja.
  • Deklarisane dozvole koje host mora provjeriti.
  • Najviše 2 MiB paketa i 1 MiB aplikacijskog sadržaja u sadašnjem ugovoru.

Proizvoljne skripte, native kod i nepodržane zavisnosti se odbijaju. Paketi sada ne uključuju prenosive fotografije i native medijske resurse.

Razvoj bez Studija

Raspakuj SDK, otvori njegov korijen i prati priloženi README. Osnovna validacija i nepotpisani paketi koriste Python standardnu biblioteku; potpisani paketi dodatno zahtijevaju cryptography 50.0.0. Testiranje izvršavanja zahtijeva Node.js.

python -m clea7 --help
python -m clea7 validate sdk/examples/units.application.json
python -m clea7 package sdk/examples/units.application.json units.clea7 --targets browser,windows,android
python -m clea7 test units.clea7 --flow convert --state '{"kilometres":2.5}'

Primjer pretvara jedinice i izrađen je nezavisno od Studija. Instaliraj njegov paket u zaseban Runtime i uporedi ponašanje sa SDK provjerom.

Šta je provjereno?

Za produktni commit e30e619 evidentirano je: 85 Python testova na Windowsu, 93 grupe Node provjera i 96 grupa Chrome provjera. Windows provjera pokrenula je stvarne Studio i Runtime prozore te potvrdila čuvanje nakon ponovnog pokretanja procesa. Android provjere izvršene su na emulatoru.

Šta još nije potvrđeno?

  • Fizički Android uređaji, force-stop/reboot i puni native tokovi birača datoteka.
  • Potpisana javna izdanja, potpuni sigurnosni pregled i univerzalna pristupačnost.
  • Opća ponovljivost efekata, potpune migracije i izolacija aplikacija u zasebne OS procese.
  • Debugiranje proizvoljnog native koda i opći Kotlin/Java projekti nisu dio CLEA7 DSL editora.
  • Globalna kvota prostora nije uvedena. Atomska zajednička kopija stanja i tabela ima posebne testove konkurentnih upisa.

Ovi rezultati potvrđuju opisani razvojni tok, ne proizvodnu spremnost niti superiornost nad drugim razvojnim okruženjima.
