Opiši ideju, pregledaj prijedlog
Opcionalno izaberi svoj OpenAI API račun, ili postojeći lokalni model. Koristi se jedan servis po zahtjevu. API potrošnju plaćaš pružaocu; pretplata za chat nije API kredit. Prijedlog nije dokaz testirane aplikacije.
Ključ ide samo lokalnom Windows hostu i izabranom HTTPS API servisu. Ne sprema se u projekt, APK, localStorage ili postavke. Prazno polje pri ponovnom povezivanju zadržava ključ istog servisa u ovoj sesiji.

Pregled prijedloga
Android aplikacija
Android paket sadrži CLEA7 Runtime biblioteku. Izvršavanje logike zahtijeva to jezgro. Za lokalni APK build potrebni su JDK 17+, Android SDK 35 i Gradle 8.10.2. Browser ne može sam izvršiti Android alatni lanac.
Ovo izdanje podržava navedene komponente i akcije. Android moduli kamere, lokacije i obavijesti zahtijevaju stvarni Android runtime i korisničke dozvole. Mrežni moduli i AI izgradnja još nisu ponuđeni kao gotove mogućnosti.
